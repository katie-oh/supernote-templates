# Weekly Planner
This weekly planner features a habit tracker, quick overview of your calendar for the week, and a todo section

## How to edit and use
The Weekly Planner PDF file in this folder has been tested with the Manta.

If you want to tweak the HTML/CSS and use it for yourself, here are some helpful steps that I used.

1. Once you're done tweaking it, open the HTML file in a browser and CTRL + P (Print). From the dropdown list of printers, there should be an option like "Save as PDF"
